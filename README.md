# Sidequest

Sidequest is a searchable directory of daily puzzles and browser games. Browse by category, bookmark games in your browser, or let Sidequest pick a random game.

## Run locally

Serve the repository with any static HTTP server. For example, run `python3 -m http.server 8000` from the repository root and open [localhost:8000](http://localhost:8000/). There are no dependencies or build steps.

The catalog is in [games.mjs](games.mjs). The games run on their respective sites.
